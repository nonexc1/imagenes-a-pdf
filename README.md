# Imágenes a PDF

Página web para convertir capturas de pantalla y fotos (del celular o de la PC) en PDF. Cada imagen sale en su propio PDF, y también se pueden descargar todas juntas en un `.zip`.

**Usar:** https://nonexc1.github.io/imagenes-a-pdf/

- Funciona en el celular y en la computadora.
- Tamaño de página: como la imagen, A4 o Carta. Márgenes y calidad ajustables.
- Todo se procesa en el navegador: las imágenes no se suben a ningún servidor.

Es un solo archivo, `index.html`. Usa [jsPDF](https://github.com/parallax/jsPDF) y [JSZip](https://github.com/Stuk/jszip) desde cdnjs.
